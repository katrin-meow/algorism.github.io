Как работать с курсом

Для каждого дня: прочитай теорию, объясни пример своими словами, выполни три самостоятельных задания и ответь на вопросы. Поле с кодом — место для собственного решения; HTML не компилирует Solidity, поэтому код нужно запускать и тестировать отдельно в Remix или другой среде.

Черновики сохраняются в браузере, чтобы не потерять ответы при перезагрузке. После успешной сдачи урока ФИО, группа, решения и баллы автоматически отправляются в Google Таблицу по указанному URL. Проверить запись в таблице нужно отдельно.

Учебный материал. Тесты оцениваются автоматически; исходники и блок-схемы проверяет преподаватель. Заявки на проверку и ссылки на файлы передаются через Google Apps Script.

Новый студент

Ведомость преподавателя

Можно использовать Google Apps Script Web App для отправки ФИО, группы, баллов и текста работы. Настройка не нужна для прохождения курса.

Автоматическая отправка включена: после каждой сдачи урока, включая пересдачи, ответы отправляются по указанному URL. При необходимости можно повторить отправку вручную.

Из-за режима no-cors браузер не может подтвердить, что Google Таблица сохранила запись. Проверяйте ведомость самостоятельно.
